# Private CV input

Place the latest CV here for local import and analysis. Supported input formats will initially be PDF and DOCX.

This directory is ignored by Git except for this file. Do not force-add CV files: the repository is intended to be public and a CV can contain phone numbers, email addresses, location details, and other personal information.

Use a descriptive local filename such as `current-cv.docx`. The application must not depend on that exact filename; import tooling should accept an explicit path.
